增长 Growth

NBS PMI 50.4 · 财新 50.8 · 出口（3月待核对）· 美ISM 52.7 · 美非农+178K
3月PMI站稳扩张区间，但这是关税战全面升级（145%）之前的数据。真正的冲击将在4月30日的PMI数据中显现——尤其是新出口订单分项。美国增长数据3月还算稳健，但领先指标（密歇根消费者信心等）已在转弱。内需导向板块（消费、基建、军工）是当前A股结构行情的逻辑底座。

通胀 Inflation

中国CPI +1.0% · PPI +0.5%（转正）· 美国CPI 3.3% · 核心PCE 3.0% · 布伦特 ~$65
中国PPI刚刚结束41个月通缩转正，但原油受双重压力（关税→需求下行 + 美伊停火谈判→供给预期恢复）跌至~$65，4月PPI能否守住正区间存在不确定性。美国通胀被关税和油价冲击抬高至3.3%，但停火带来的油价回落是4月CPI的潜在缓和因素。

流动性 Liquidity

DR007 1.49% · 中国10Y 1.80% · Fed 3.50-3.75% · 美国10Y 4.33%（本周异常波动）
中国流动性是当前宏观环境中最稳定的正面信号：DR007低位，央行明确宽松立场，降准预期升温。美国方面，美债本周经历罕见波动（避险→外国机构疑似减持→急升至4.6%→回落），对美元资产信用的隐忧初步浮现，黄金创历史新高正是这一担忧的体现。

A · 中国增长指标
制造业PMI（官方 / 财新）
Manufacturing PMI · Purchasing Managers' Index
📊 工厂的"月度体检报告"，50是荣枯线
每月对大量制造业企业采购经理做问卷：订单多不多？招人了吗？原材料贵不贵？把所有回答汇成一个数字。

50 = 分界线：高于50 = 大多数工厂在扩张；低于50 = 大多数在收缩。注意：低于50不代表崩溃，只是"变差"。

官方 vs 财新：官方PMI以大型国企为主；财新PMI以私营中小企业为主，两者经常有差异，要一起看。
✅ 对A股：PMI持续高于50且回升 → 企业盈利预期改善 → 股市偏正面
工业增加值
Industrial Value Added (IVA) · YoY%
🏭 全国工厂这个月"创造了多少新价值"
工厂产出的总价值，减去原材料成本，剩下的就是"增加值"。同比增速反映工业生产的扩张或收缩速度。

由国家统计局每月中旬发布（通常与GDP、社零同一天）。

为什么显示"待核对"：这条数据已于4月17日由统计局正式发布，但我没有实时联网能力，无法自动抓取。请前往 stats.gov.cn 查询后手动填入。
✅ 对A股：工业增加值增速加快 → 利好周期类（钢铁/化工/机械）板块
社会消费品零售总额（社零）
Retail Sales · YoY%
🛒 全国老百姓这个月在商店、餐厅、网购花了多少钱
包括商品零售和餐饮收入，是衡量消费能力最直接的指标。春节、国庆节期间数字会季节性偏高。

同样于4月17日发布，需手动查询填入。与工业增加值同步发布。
✅ 对A股：社零持续回升 → 消费板块（食品/零售/旅游）受益
出口同比
Exports YoY% (USD-denominated)
✈️ 这个月中国卖给外国的东西，比去年同月多多少
用美元计算，由海关总署每月发布。受汇率、全球需求、贸易政策影响极大。

今年特殊背景：关税战爆发前企业"抢出口"，导致Jan-Feb数据异常高（+21.8%）。3月数据已发布，需手动核对。
✅ 对A股：出口强 → 纺织/机械/电子出口链受益；但145%关税下此逻辑当前受压
地产开发投资
Real Estate Development Investment · YoY%
🏠 房地产开发商花了多少钱拿地、建房子
持续多年负增长，反映中国房地产行业深度调整。因为地产链涉及建材、家居、家电等众多行业（占GDP约15-20%），所以它的走向对整体经济影响很大。

降幅收窄（如从-17%收窄到-11%）也算积极信号，因为说明下行速度在放慢。
⚠️ 对A股：地产投资持续负增长 → 地产链长期承压；政策刺激是主要博弈点
B · 中国通胀指标
CPI — 居民消费价格指数
Consumer Price Index · YoY%
🧾 衡量你买东西变贵了多少
统计一篮子代表性商品（大米、猪肉、房租、医疗等）的价格变化。

同比为正 = 通胀（物价比去年贵）；同比为负 = 通缩（物价比去年便宜，听起来好但其实意味着需求不足）。

核心CPI：剔除食品和能源（波动大的项目）后的CPI，反映更持久的通胀压力。当前核心CPI +1.1%，说明底层通胀温和。
✅ 对A股：CPI温和正区间（0.5-3%）最友好；持续通缩或过热都是风险
PPI — 工业品出厂价格指数
Producer Price Index · YoY%
🏗️ 工厂卖出原材料和产品的价格，涨了还是跌了
PPI是CPI的"上游"，工厂价格上涨最终会传导到消费者价格。

本周重要信号：PPI同比从-0.9%升到+0.5%，结束了长达41个月（3年多）的通缩。这意味着工业品价格压力缓解，有利于企业利润恢复。

风险：油价回落（$95→$65）可能让4月PPI重回负区间，需要密切关注。
✅ PPI转正 → 利好中上游制造业利润；是"再通胀交易"的核心线索
C · 中国流动性与利率指标
社会融资规模（社融）
Total Social Financing (TSF) / Aggregate Financing
💰 全社会这个月从金融系统借到了多少钱
不只是银行贷款，还包括企业债券、股票融资、信托贷款等所有渠道。是衡量"信用扩张"最全面的指标。

社融增量大 = 钱在往实体经济流；社融收缩 = 经济"缺水"。

通常在月中由人民银行公布，3月数据约在4月10-15日发布。需手动查询人民银行官网填入。
✅ 社融超预期 → A股上涨的重要催化剂，尤其是金融和地产板块
贷款余额增速
Loan Balance Growth · YoY%
🏦 银行贷出去的总钱量，在增长还是萎缩
当前+6.0%创二十年新低，说明：即便利率低、钱很充裕，企业和居民借钱的意愿也不高。这是中国经济当前面临的核心挑战之一——"流动性陷阱"的迹象。

好比水龙头开着，但没人接水。
⚠️ 贷款增速持续低迷 → 政策宽松效果打折，需更强财政刺激配合
DR007
7-Day Interbank Repo Rate (Depository Institutions)
🌡️ 银行之间互借7天钱的利率，是中国短端利率的"体温"
DR = Depository-institution Repo（存款类机构质押式回购）。可以理解为：银行间"隔夜拆借"的成本。

数字越低 = 市场上钱越充裕、借钱越容易。央行通过公开市场操作（逆回购）来调控这个利率。

当前1.49%，与7天逆回购政策利率持平，说明资金面宽松。
✅ DR007低位 → 资金面宽松，有利于股市（尤其成长股）
10年期国债收益率
10-Year Government Bond Yield (CGB)
📐 国家借10年期钱需要付多少利息，资产定价的长端基准
国债是最安全的资产，其收益率是衡量"长期无风险利率"的基准，影响股票、房产、债券等所有资产的估值。

收益率下行 = 市场避险情绪升温 或 宽松预期增强；上行 = 经济预期改善 或 供给压力增加。

当前1.80%，处于历史低位，说明市场对长期增长预期偏保守。
⚠️ 利率低 → 债券吸引力高，对股市影响中性；利率快速上行会压制高估值成长股
D · 汇率指标
USD/CNY — 美元兑人民币
US Dollar / Chinese Yuan Exchange Rate
💱 1美元能换多少人民币
数字越大 = 人民币越弱（贬值）；数字越小 = 人民币越强（升值）。

W15时是6.83（美伊停火 + 美元弱推动人民币升至3年新高）；W16/W17当前约7.22（关税战压力 + 美元整体走弱，央行管控中间价）。

贬值影响：有利于出口商（收美元折算人民币变多）；不利于进口商和有美元债务的企业。
⚠️ 人民币大幅贬值 → 可能引发资本外流，外资减持A股
CFETS人民币指数
CFETS RMB Index (China Foreign Exchange Trade System)
🌐 人民币对一篮子货币的综合强弱，比单看美元更全面
由中国外汇交易中心编制，包含对欧元、日元、英镑等24种货币的汇率加权平均。

好处：如果美元大幅走弱，USD/CNY数字下降（人民币升值），但CFETS可能变化不大，因为人民币对欧元等其他货币没有同步升值。

CFETS持续下行 = 人民币在综合意义上走弱，需关注资本流动压力。
⚠️ CFETS快速走弱 → 人民币综合贬值信号，关注外资动向
E · 美国宏观指标
非农就业（NFP）
Non-Farm Payrolls
👷 美国上个月新增了多少份工作（农业除外）
每月第一个周五由美国劳工统计局（BLS）发布，全球最重要的单一经济数据之一。

超预期 = 美国经济强劲 → 美联储推迟降息 → 美债利率高位 → 美元偏强 → 全球资金倾向留在美元资产。

本月+178K，大幅超预期（前值-133K），说明就业市场韧性强。
⚠️ 非农超预期 → 降息推迟 → 全球流动性偏紧，间接压制A股外资流入
ISM制造业/服务业PMI（美国）
ISM Manufacturing / Services PMI
🇺🇸 美国版PMI，由供应管理协会（ISM）编制
与中国PMI逻辑完全相同，>50扩张，<50收缩。美国服务业占GDP约70%，服务业PMI通常更重要。

当前：制造业52.7（连续3月扩张）、服务业54.0（连续21月扩张），说明关税冲击尚未传导到企业层面——4月数据是观察关税影响的关键节点。
⚠️ 美国PMI转弱 → 全球需求下行信号，中国出口链承压
美国CPI
US Consumer Price Index · YoY%
📈 美国版的"物价涨了多少"，当前因油价冲击处于高位
由美国劳工统计局每月发布。美联储的目标是2%，当前3.3%远高于目标。

为什么这么高？主要因为美伊战争推升能源价格（汽油+18.9%，燃油+44.2%），带动整体CPI跳升。

停火谈判推进 + 油价回落，可能让4-5月CPI有所下降。
🔴 美国CPI高 → 美联储不敢降息 → 全球成长股估值持续承压
核心PCE
Core Personal Consumption Expenditures Price Index · YoY%
🎯 美联储最关注的通胀指标，剔除了食品和能源的短期波动
"核心"= 剔除食品和能源价格（这两项波动很大，会干扰判断）。PCE与CPI略有不同：PCE覆盖范围更广，包含医疗保险等项目。

美联储明确表示以核心PCE 2%为通胀目标。当前3.0%，仍显著高于目标，是阻碍降息的主要因素。
🔴 核心PCE不降到2%附近，美联储降息就很难落地
联邦基金利率
Federal Funds Rate (Fed Funds Target Range)
🏛️ 美联储设定的美国基准利率，全球资金成本的"锚"
美联储通过FOMC（联邦公开市场委员会）每6-8周开会决定利率。当前3.50-3.75%，相当于把钱存入美国银行的近似无风险收益率。

这个数字越高 → 全球资金越倾向于留在美元资产（因为安全又有收益）→ 新兴市场和A股外资流出压力越大。

降息 = 美元资产吸引力下降 → 资金分散到全球其他市场，是A股重要利好信号。
✅ 美联储降息 → 全球流动性改善，A股北向资金有望回流
10年期美债收益率（DGS10）
US 10-Year Treasury Yield
⚓ 全球所有资产定价的"地基"，是最重要的单一利率指标
全球股票、债券、房地产的估值都与它有关。逻辑是：如果不冒任何风险就能赚4%+，那么冒风险的资产（股票）就必须提供更高的预期回报，否则估值就会被压低。

本周特殊事件：本周美债出现罕见的"避险资产反而下跌"——起初利率下行（资金避险），随后疑似外国机构大量抛售美债，利率急升至~4.6%，后回落至4.33%。这是对美元信用产生怀疑的早期信号，黄金创新高与此有关。
⚠️ 美债利率高位 → 压制全球成长股估值，也影响北向资金机会成本
10年期TIPS实际利率
10-Year TIPS Real Yield (Treasury Inflation-Protected Securities)
📊 剔除通胀后，投资美债的"真实"回报率
TIPS = 通胀保值国债。实际利率 ≈ 名义利率 - 通胀预期。

举例：美债利率4.33%，通胀预期~2.3%，实际利率≈2.0%。说明扣除通胀后持有美债仍有2%的真实收益，对其他资产（黄金、成长股）形成竞争。

实际利率越高，没有现金流的资产（黄金、高估值科技股）估值越承压。
⚠️ 实际利率高 → 黄金和成长股估值承压（黄金本周创新高反映的是对美元信用的担忧，抵消了实际利率的压制）
DXY — 美元指数
US Dollar Index
💵 美元对欧元、日元、英镑等主要货币的综合强弱
一篮子6种货币，欧元权重最大（约58%）。100是历史中等水平的参考线。

当前~99.3，跌破100关口，说明美元在走弱。美元弱通常：① 大宗商品价格上涨（因为用美元定价）；② 新兴市场货币相对升值；③ 外资流入非美元资产。

但美元弱的原因也很重要——如果是因为美国经济预期恶化，则对全球不一定是好事。
✅ 美元适度走弱 → 人民币承压减轻，对A股和大宗商品有一定正面效应
VIX — 恐慌指数
CBOE Volatility Index
😱 衡量市场"有多害怕"，数字越高越恐慌
通过计算标普500期权的隐含波动率得出，反映市场对未来30天波动的预期。

参考刻度：
<15 = 非常平静 | 15-25 = 正常 | 25-35 = 紧张 | >35 = 恐慌 | >50 = 极度恐慌

本周4/7曾触及~52（极度恐慌），之后随着部分企稳回落至~31（仍处"紧张"区间）。
🔴 VIX>30 → 全球风险偏好受压，外资撤离新兴市场包括A股；VIX回落是修复信号
HY信用利差
High-Yield (HY) Credit Spread
📉 高风险企业比政府多付多少利息，衡量市场对违约风险的担忧
HY（High Yield）= 高收益债 = 俗称"垃圾债"，是信用评级较低企业发行的债券。

信用利差 = HY债收益率 - 同期美债收益率。利差越大，市场认为这些企业越可能违约，风险偏好越低。

当前~420bp（较W15的294bp大幅走阔），反映关税引发的企业盈利下行担忧。历史均值约490bp，当前仍低于均值，但快速走阔本身是警示信号。
⚠️ 信用利差快速走阔 → 全球风险厌恶情绪升温的早期信号，通常领先股市调整
F · A股市场指标
上证综指 / 深证成指 / 创业板指
Shanghai Composite / Shenzhen Component / ChiNext Index
📈 三个衡量A股整体涨跌的"温度计"
上证综指：上海交易所全部股票加权平均，以大盘蓝筹（银行、能源、消费）为主，最"稳"。

深证成指：深圳交易所主要股票，中等规模公司为主，更偏成长。

创业板指：深圳创业板，科技、医疗、新能源等成长型企业，波动最大，对风险偏好最敏感。

三个一起看可以判断是"全面上涨"还是"结构性行情"（只有某类股票涨）。
✅ 三大指数分化 → 说明市场有明显的风格轮动，需要选对方向
北向资金
Northbound Capital Flow (Stock Connect)
🌊 通过沪深港通从香港流入A股的外资净买入
沪港通（2014年）和深港通（2016年）开通后，境外投资者可以通过香港直接买卖A股。"北向"指从香港（南）流向内地（北）。

净流入 = 外资买入多于卖出；净流出 = 反之。

为什么显示"待更新"：没有现成API提供"周合计"数据，需手动到东方财富网站，把周一到周五每日净买额加总。数据更新后直接修改HTML文件中的数字即可。

注意：北向只是外资进入A股渠道之一，不代表全部外资。
✅ 北向持续净流入 → 外资看好A股，推动蓝筹估值；持续净流出是风险信号
融资余额（两融）
Margin Financing Balance
⚡ 投资者向券商借钱炒股，目前还没还清的总金额
融资 = 借钱买股票（看涨，加杠杆）；融券 = 借股票卖出（看跌，做空）。"两融余额"通常指融资余额。

这个数字越高，说明市场"加杠杆"越多：情绪越积极，但系统性风险也越大——暴跌时杠杆会放大损失，可能引发强制平仓。

当前约2.45万亿，较历史高位有所回落（关税冲击后去杠杆）。
⚠️ 融资余额快速下降 → 市场去杠杆，往往伴随或预示调整；持续高位说明情绪仍可
ETF（交易所交易基金）
Exchange-Traded Fund
📦 像股票一样在交易所买卖的基金，通常跟踪某个指数
比如"沪深300ETF"就是跟踪沪深300指数的基金，买一手等于同时持有了300只股票，分散风险。

国家队与ETF：当市场大跌时，汇金公司等国家队机构会大量买入宽基ETF（如沪深300ETF、CSI A500 ETF）来稳定市场，俗称"国家队托底"。这是A股特有的市场稳定机制。

ETF申购（有人买）= 钱流入市场；ETF赎回（有人卖）= 钱流出市场。
✅ 国家队大量买入宽基ETF → 市场下行有支撑；ETF持续净赎回是看空信号
全A成交额
Total A-share Daily Turnover
🔥 沪深两市所有A股一天交易了多少钱，是市场情绪的"体温表"
成交额高 = 市场活跃、情绪高涨、资金在积极参与；成交额持续萎缩 = 观望情绪浓、方向感缺失。

参考刻度（2026年）：
<1万亿 = 偏低（地量）| 1-1.5万亿 = 温和 | 1.5-2万亿 = 活跃 | >2万亿 = 高度活跃

4月初曾达2.45万亿，关税冲击后缩至约1.5万亿，说明市场情绪转为等待观望。

G · 框架术语与读法
四象限宏观框架
Four-Quadrant Macro Framework
🧭 用四个维度理解市场环境，避免只看一个指标做判断
没有任何单一指标能完整解释市场。这个框架把所有影响A股的宏观力量归为四类：

① 增长：经济在扩张还是收缩？（PMI、工业、消费）
② 通胀：价格在涨还是跌？（CPI、PPI）
③ 流动性：钱好借、成本低吗？（DR007、国债收益率、社融）
④ 风险偏好：投资者敢冒险吗？（VIX、成交量、北向、两融）

最理想组合：增长↑ + 通胀温和 + 流动性宽松 + 风险偏好高。
最糟糕组合（滞胀）：增长↓ + 通胀高 + 流动性紧 + 风险偏好低。
💡 当四个维度出现分歧时，需要判断哪个维度是主导力量
信号灯（绿 / 黄 / 红）
Signal Light System
🚦 对每个指标是否有利于A股的快速判断标签
● 绿色：当前数值对A股风险资产偏有利（例：PMI>50且回升）

● 黄色：中性，需要继续观察，无明显方向（例：CPI温和正区间）

● 红色：当前数值对A股有明显逆风（例：VIX>30，美国CPI 3.3%）

重要提醒：这是简化的定性判断，不是精确模型，也绝对不是买卖信号。同一个指标在不同背景下意义可能不同。信号灯是"讨论的起点"，不是"决策的终点"。
💡 不要机械地数绿灯多就买、红灯多就卖，要理解每个灯背后的逻辑
同比（YoY）vs 环比（MoM）
Year-over-Year vs Month-over-Month
📅 同比 = 跟去年同月比；环比 = 跟上个月比
同比（YoY）：消除了季节性因素，反映长期趋势。例：3月CPI同比+1.0% = 今年3月物价比去年3月贵1%。

环比（MoM）：反映最新变化方向，但受季节性影响大。例：3月CPI环比-0.7% = 今年3月比今年2月便宜了0.7%（春节后需求季节性回落，这是正常现象，不代表通缩）。

读数时的陷阱：环比为负不一定是坏事（可能只是季节性），同比很高也可能是去年基数太低（"低基数效应"）。
💡 看长期趋势用同比；判断最新拐点用环比；两者要结合看
基点（bp）
Basis Point (bp)
🔢 利率变化的最小单位，1bp = 0.01%
100bp = 1%。金融界用基点是因为利率变化幅度通常很小，用基点表达更精确且不容易混淆。

常见说法：
"美联储降息25bp" = 利率降了0.25%
"信用利差走阔126bp" = 利差从294bp扩大到420bp
"美债上行20bp" = 收益率上升了0.20%（如从4.33%升到4.53%）
💡 听到"bp"就等于0.01%，听到"ppt"就等于百分比的绝对变化量
情景推演
Scenario Analysis
🔮 把未来可能发生的情况整理成框架，提前想好应对逻辑
我们把未来分为三种情景：基准（最可能）、乐观（好的结果）、悲观（坏的结果）。每种情景赋予主观概率，合计100%。

重要说明：概率是主观判断，不是模型输出，每周根据新信息调整。本周悲观概率35%>乐观25%，反映当前不确定性偏高。

作用：提前想清楚"如果X发生，我们应该做什么"，避免事情真的发生时手忙脚乱。
💡 情景推演不是预测，而是让团队对"可能的未来"有共同的讨论语言
Watchlist / 触发器
Watchlist / Market Triggers
🔔 "如果…就关注…"的行动清单，不是预测，是预案
每一条的格式是：
【条件】某个指标达到某个阈值
→【动作】应该关注的风险或机会

使用方法：每周开会时浏览一遍，问"这周有没有哪条被触发了？"如果有，就重点讨论那条对应的动作。

注意："条件成立"不等于"一定要卖/买"，而是"进入更高警戒状态，重新审视判断"。

本周最重要的两条：① 中美关税谈判突破（乐观触发器）；② 美伊停火破裂（悲观触发器）。
💡 每周回顾Watchlist = 把宏观分析落地为可执行的观察动作
荣枯线
Boom-Bust Line / PMI Threshold of 50
⚖️ PMI的50分界线，像经济活动的"零度"
PMI = 50 是扩张和收缩的分水岭。

>50 = 大多数企业回答"情况在变好" = 扩张
<50 = 大多数企业回答"情况在变差" = 收缩

注意：<50不代表经济崩溃，只是说"比上月更差"的企业比"比上月更好"的企业多。从49跌到48是负面信号，但从48涨到49也是积极信号（改善方向）。

本周NBS PMI 50.4，跨越荣枯线，是积极信号。
💡 PMI连续两个月低于49，通常被视为需要关注的经济下行信号
ppt（百分点）
Percentage Points (ppt)
📏 百分比的绝对变化量，与"百分比变化"不同
容易混淆的概念：

百分点（ppt）：两个百分比数字相减。例：PPI从-0.9%升到+0.5%，变化了+1.4个百分点（ppt）。

百分比变化（%）：相对变化。如果某个值从10%变为11%，那是增加了1个百分点，但也是增加了10%（相对于原来的10%）。

在宏观分析中，说"CPI下降了0.3ppt"比说"CPI下降了0.3%"更准确，因为它明确表示是绝对值的变化。
💡 听到"ppt"就是两个百分比相减；不要和"百分比变化"混淆
