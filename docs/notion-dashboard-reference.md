## 1. 周更与协作：下周给团队展示时怎么做

### 日常周更（自己操作）

- 主要内容在 **`js/data.js`**：更新 `meta`、摘要、KPI、框架、A 股区、美股区、Watchlist 等。
- 保存后执行：

```bash
cd /Users/yubinshen/Projects/a-share-macro-dashboard
git add js/data.js
git commit -m "Weekly update YYYY-MM-DD"
git push
```

- 若改了多个文件，可用 `git add -A` 代替只加 `data.js`。

### 与 AI 协作（你来找我更新）

| 做法 | 说明 |
|------|------|
| **你提需求** | 说明「数据截止某日 / 第几周」等，由 AI 根据公开来源协助**改写 `data.js` 中的文案与数字**。 |
| **你发布** | 你在本机保存 → `git add` → `git commit` → `git push`；若使用 **GitHub Pages**，推送后线上链接会更新。 |
| **`index.html`** | **日常周更通常不必改**；仅当调整页面结构、新增区块、改样式时才需动。 |
| **`css/main.css` / `js/app.js`** | 仅在有样式或交互需求时修改。 |

**结论：** 可以固定采用「AI 协助写好 `data.js` → 你提交推送」的方式；**一般不需要对 `index.html`「倒带」或重改。**

### 可选：线上访问（GitHub Pages）

- 仓库 **Settings → Pages**：Branch 选 `master`，目录选 `/ (root)`。
- 发布后得到类似：`https://<用户名>.github.io/a-share-macro-dashboard/`
- 之后每次 **`git push`**，页面内容随最新提交更新（可能有短延迟）。

### 「自动每天打开链接就更新数字」（曾讨论、已搁置）

- **静态站 + 仅 `data.js`：** 页面展示的是**最后一次 push 的提交**；不 push 则内容不变。
- **真正自动：** 需 **定时任务（如 GitHub Actions）拉数并提交**，或 **页面加载时调 API**（常需后端/代理解决跨域）。此方向可日后单独做，当前以**手动/半手动周更 `data.js`**为主。

## 2. 术语与指标：定义 + 数据从哪来

> 频率以惯例为准，具体发布日以各官网为准。

### A. 增长（Growth）

| 名称 | 英文 / 简称 | 是什么 | 怎么看（极简） | 常见发布 / 查询 |
|------|---------------|--------|------------------|-----------------|
| **制造业 PMI** | Manufacturing PMI | 对采购经理的月度调查汇总成的景气指数，**50 为荣枯线**。 | \>50 扩张，\<50 收缩；环比看短期动能。 | 中国：[国家统计局](https://www.stats.gov.cn)（检索「采购经理指数」PMI 新闻稿） |
| **工业增加值同比** | Industrial production YoY | 规模以上工业企业产出相对去年同月的增速。 | 反映工业生产强弱。 | 国家统计局月度数据 |
| **社会消费品零售总额同比** | Retail sales YoY | 商品+餐饮等消费相对去年同月增速。 | 反映消费侧。 | 国家统计局 |
| **出口同比** | Exports YoY | 出口金额相对去年同月。 | 外需、全球周期。 | 海关总署 / 国家统计局 |

### B. 通胀（Inflation）

| 名称 | 英文 / 简称 | 是什么 | 怎么看（极简） | 常见发布 / 查询 |
|------|---------------|--------|------------------|-----------------|
| **CPI 同比** | Consumer Price Index YoY | 一篮子消费品及服务相对**去年同月**的价格变化。 | 居民端通胀、政策关注的总体物价。 | [国家统计局 CPI/PPI](https://www.stats.gov.cn) |
| **PPI 同比** | Producer Price Index YoY | 工业品出厂价格相对**去年同月**。 | 偏生产端/上游价格，影响企业利润预期。 | 同上 |
| **核心 CPI** | Core CPI | 剔除食品和能源后的 CPI（各国口径略不同）。 | 减少短期波动，看粘性通胀。 | 国家统计局解读稿中常给出 |

### C. 流动性与利率（Liquidity / Rates）

| 名称 | 英文 / 简称 | 是什么 | 怎么看（极简） | 常见发布 / 查询 |
|------|---------------|--------|------------------|-----------------|
| **DR007** | 存款类机构 7 天回购利率 | 银行间存款类机构 7 天质押式回购**加权平均利率**，常作短端资金面参考。 | 与 OMO（逆回购）等政策利率对比，看资金面松紧。 | [中国人民银行](https://www.pbc.gov.cn) 金融市场运行情况 |
| **M1 / M2** | Money supply | M1 偏「活钱」，M2 更广义的货币量。 | M1 变化有时与交易活跃度相关（需结合结构）。 | 人民银行统计数据 |
| **社会融资规模** | Aggregate financing | 一定时期内实体经济从金融体系获得的资金总额（增量常公布）。 | 信用扩张总量的重要指标。 | 人民银行 |
| **10 年期国债收益率** | 10Y government bond yield | 剩余期限约 10 年的国债到期收益率。 | 长端利率、增长与通胀预期、资产定价锚之一。 | 中债 / 中国货币网 / 财经终端 |

### D. 汇率与外部（FX / External）

| 名称 | 英文 / 简称 | 是什么 | 怎么看（极简） | 常见发布 / 查询 |
|------|---------------|--------|------------------|-----------------|
| **USD/CNY** | 美元兑人民币 | 美元相对人民币汇率（有中间价、即期等）。 | 贬值/升值影响外债、进口成本、风险偏好等（需分情景）。 | 中国外汇交易中心 / 央行 |

### E. A 股市场类（A-share market）

| 名称 | 英文 / 简称 | 是什么 | 怎么看（极简） | 常见发布 / 查询 |
|------|---------------|--------|------------------|-----------------|
| **北向资金** | Northbound (Stock Connect) | 经沪深港通从香港流入 A 股的净买入额（有日度，可**按周加总**）。 | 外资流向的近似指标（不等于全部外资）。 | [东方财富 沪深港通](https://data.eastmoney.com/hsgt/hsgtV2.html) |
| **融资余额** | Margin balance | 投资者向券商借钱买股的未偿还融资规模。 | 杠杆情绪。 | 上交所/深交所 / 东方财富数据中心 |
| **融券余额** | Short selling balance | 借券卖出的规模。 | 做空力量（需结合规则变化）。 | 交易所 |
| **全 A 成交额** | Total A-share turnover | 沪深两市股票成交总金额。 | 流动性与情绪；可算历史分位。 | 交易所日度 |
| **行业强弱 Top/Bottom** | Sector performance | 常用申万/中信/中证行业指数区间涨跌幅排序。 | 结构行情、轮动。 | 行情软件 / 东方财富板块 |

### F. 美国宏观与美股（US / Global）

| 名称 | 英文 / 简称 | 是什么 | 怎么看（极简） | 常见发布 / 查询 |
|------|---------------|--------|------------------|-----------------|
| **联邦基金目标区间** | Federal funds target range | 美联储政策利率目标区间。 | 全球利率锚之一。 | [美联储 FOMC](https://www.federalreserve.gov/monetarypolicy/openmarket.htm) |
| **非农就业 / 失业率** | NFP, unemployment | 新增非农、失业率。 | 美国增长与劳动力市场。 | BLS / [FRED](https://fred.stlouisfed.org) |
| **CPI / 核心 PCE** | CPI, Core PCE | CPI：消费物价；核心 PCE：美联储常盯的通胀指标之一。 | 通胀与降息路径预期。 | BLS / BEA / FRED |
| **10 年期美债收益率** | US 10Y Treasury yield | 常用序列 **DGS10**。 | 全球无风险利率锚、成长股估值等。 | [FRED DGS10](https://fred.stlouisfed.org/series/DGS10) |
| **10 年期 TIPS 实际利率** | 10Y TIPS real yield | 常用序列 **DFII10**。 | 实际利率与风险资产定价。 | [FRED DFII10](https://fred.stlouisfed.org/series/DFII10) |
| **VIX** | CBOE Volatility Index | 标普 500 期权隐含的波动率预期（「恐慌指数」）。 | 高则预期波动大，风险偏好常受压。 | [FRED VIXCLS](https://fred.stlouisfed.org/series/VIXCLS) |
| **美元指数 DXY** | US Dollar Index | 美元对一篮子货币强弱。 | 强美元常影响新兴市场与大宗商品计价。 | ICE / 财经终端 / FRED 相关序列 |
| **标普 500 / 纳斯达克** | S&P 500, Nasdaq | SPX：大盘股指数；纳指综合/纳指 100 为不同指数。 | 美股整体与成长风格。 | 交易所 / 财经网站 |

### G. 看板常用「框架」用语

| 名称 | 含义 |
|------|------|
| **四象限 / 宏观框架** | 将宏观拆成 **增长、通胀、流动性、风险偏好** 四块，每块用少量指标概括。 |
| **KPI 卡** | 每指标一张卡：最新值、变化、灯色、更新时间、来源链接。 |
| **环比 / 同比** | **同比**：与去年同月比；**环比**：与上期比（注意季节性）。 |
| **信号灯（绿 / 黄 / 红）** | 结合经济含义与简单规则的**粗标签**，非唯一标准答案。 |
| **Watchlist / 触发器** | 「若某条件成立 → 关注某类风险或机会」的清单。 |
| **情景推演** | 基准/乐观/悲观叙事 + 主观概率 + 验证指标，**非官方预测**。 |

## 3. 看板各区块在干什么

| 区块 | 作用 |
|------|------|
| **摘要** | 几句话概括市场主线、风险偏好、对 A 股/美股的定性判断。 |
| **指标卡（KPI）** | 关键数据表格化，带来源，便于团队对齐「我们看哪些数」。 |
| **四象限框架** | 从增长/通胀/流动性/风险偏好四角覆盖，避免单点判断。 |
| **A 股结构与资金** | 行业强弱 + 资金面（北向、两融、成交额等）。 |
| **美股对照** | 利率、美元、美股指数等外部约束。 |
| **情景推演** | 用概率叙事组织讨论。 |
| **Watchlist** | 下周盯哪些条件、触发后关注什么。 |
| **页脚 · 口径说明** | 灯色规则与数据局限，避免误解为投资建议。 |

## 4. 数据与结论的边界

- **原始数字**以统计局、央行、交易所、FRED 等官方或权威发布为准；看板文字为**解读**，不能替代原始发布。
- **绿 / 黄 / 红** 为便于讨论的**粗标签**，**不是**买卖信号或模型最优解。
- **北向周合计、成交额分位** 等往往需在数据源页面**自行加总或自建序列**，未必能全自动（除非后续接 API/脚本）。

## 5. 附录：推送 GitHub 常见问题（简记）

### 为什么会出现 401 / 403？

- **HTTPS：** GitHub **不接受账户密码** 用于 `git push`，需 **Personal Access Token（classic，勾选 `repo`）** 代替密码；**细粒度令牌**须对该仓库勾选 **Contents: Read and write**。
- **403 “Write access not granted”：** 多为令牌只读、或电脑里缓存了**错误账号**的旧凭据（可清理 macOS **钥匙串** 里 `github.com` 相关项后重试）。

### SSH 是什么？为何最后改用 SSH？

- **SSH** 是一套**加密远程登录**协议；用于 GitHub 时，用**密钥对**（本机私钥 + 网站登记公钥）证明身份，**无需在每次 push 时输入 HTTPS 令牌**。
- **曾出现的问题：**  
  1）`Host key verification failed` → 需将 `github.com` 主机密钥写入 `~/.ssh/known_hosts`；  
  2）`Permission denied (publickey)` → 需在 GitHub **Settings → SSH keys** 添加本机 `*.pub` 公钥；  
  3）远程地址从 `https://github.com/...` 改为 `git@github.com:用户名/仓库.git` 后，用 **`git push`** 走 SSH。

### 手动上传网页到 GitHub

- 在仓库页 **Add file → Upload files** 可上传 `index.html`、`css/`、`js/` 等，**不必**用命令行；但长期维护通常仍推荐 Git 或 GitHub Desktop。
